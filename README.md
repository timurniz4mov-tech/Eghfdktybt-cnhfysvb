# Живые цивилизации — Forge 1.20.1

**Статус: Alpha 0.1.0.** Это исходный проект первого игрового этапа, а не заявление о завершённом моде со всеми функциями из большой концепции. Сборка настроена под Minecraft Java 1.20.1, Forge 47.2.0 и Java 17. Проект не требует сторонних модов.

## Что уже заложено в этой версии

- Отдельные сущности с собственными 64×64 текстурами: путник, торговец, караванный торговец, работяга, фермер, шахтёр, строитель, стражник, воин, лорд, король и разбойник.
- Путник и караванный торговец перемещаются по миру; стационарный торговец остаётся на месте. Путник может останавливаться в деревнях (в том числе в созданных модом поселениях, распознаваемых по кровати и колоколу). Путники могут появляться с посохом.
- Стражники и воины нападают на разбойников. Разбойники ищут игроков и небоевых NPC и атакуют их в ближнем бою.
- Случайное снаряжение по уровням: деревянное, каменное, железное и алмазное оружие/инструменты; кожаная, кольчужная, железная и алмазная броня.
- В генерации мира есть простые поселения с домом, кроватью, колоколом, грядкой, NPC и дорогой, а также каменные замки с королём, лордом, охраной и караванным торговцем. Путник появляется у поселения и может остановиться там на отдых.
- В мире иногда генерируются небольшие лагеря разбойников с палатками, костром, припасами и охраной.
- Дороги состоят из **полных блоков** гравия и булыжника/каменных кирпичей. Плиты и тонкие дорожные блоки в них не используются.
- Профессии игрока: `miner`, `lumberjack`, `farmer`, `builder`, `guard`, `warrior`, `trader`. Игрок получает деньги за добычу подходящих блоков, рубку брёвен, сбор урожая, строительство и убийство разбойников (для боевых профессий).
- Торговцы продают хлеб или железные слитки за внутриигровой баланс. Игрок с профессией `trader` может продавать предмет из основной руки командой `/civ sell`.
- Игрок может основать королевство, покупать соседние участки по чанкам и объявлять войну другому королевству. Данные сохраняются в мире.
- Предмет карты выводит список известных королевств и количество принадлежащих им чанков.

## Честно о том, чего пока нет

Это именно первый этап. Пока **не реализованы**: полноценная графическая мини-карта с рельефом и цветными границами; автономный ИИ-король, который сам выбирает причины войн; реальная система дипломатии/союзов; торговые маршруты между конкретными поселениями; полноценная работа шахтёров/фермеров/строителей (NPC пока носят инструменты, перемещаются и взаимодействуют с угрозами, но не выполняют сложные рабочие циклы); автоматический рост новых домов; отдельные анимации и собственные звуковые эффекты. Сгенерированные поселения и замки — компактные процедурные постройки, а не большие вариативные структуры с десятками комнат.

Карта сейчас текстовая: она показывает сохранённые королевства и число участков, а не рисует мини-карту местности. Не устанавливай эту Alpha, ожидая, что уже работает каждая механика из полного описания.

## Команды

- `/civ help` — справка.
- `/civ money` — баланс.
- `/civ job miner` — выбрать шахтёра. Другие профессии: `lumberjack`, `farmer`, `builder`, `guard`, `warrior`, `trader`.
- `/civ sell` — продать предмет из основной руки (нужна профессия `trader`).
- `/civ kingdom create Northland` — основать королевство в текущем чанке.
- `/civ kingdom claim Northland` — купить текущий чанк за 100 монет; покупать может только основатель.
- `/civ kingdom war Southland` — объявить войну существующему королевству.
- `/civ map` — вывести текстовый список королевств.
- `/civ spawn traveler` — призвать NPC (требуется OP/permission 2). Роли: `traveler`, `trader`, `caravan_trader`, `worker`, `farmer`, `miner`, `builder`, `guard`, `warrior`, `lord`, `king`, `bandit`.

Яйца призыва доступны командами `/give @p livingcivilizations:traveler_spawn_egg 1` и по аналогии для остальных типов.

## Сборка через GitHub Actions

В репозитории уже есть `.github/workflows/build.yml`. GitHub Actions ставит Java 17 и Gradle 8.1.1, выполняет `gradle build --no-daemon` и публикует JAR как артефакт workflow.

1. Загрузи содержимое проекта в отдельную ветку GitHub, чтобы не перезаписать текущую рабочую версию.
2. Открой вкладку **Actions** и запусти workflow **Build Living Civilizations (Forge 1.20.1)**.
3. Когда задача завершится успешно, открой её страницу и скачай artifact `living-civilizations-forge-1.20.1`.
4. Распакуй artifact и положи полученный `.jar` в папку `mods` профиля Forge 1.20.1.

Для игры нужен **Minecraft Java 1.20.1 + Forge 47.x + Java 17**. Мир лучше создать новый: новые объекты генерации появляются только в ещё не сгенерированных чанках. Перед тестированием сделай резервную копию мира.

## Проверка

В этой среде нет Gradle 8.1.1 и нет доступа к загрузке Forge Maven-зависимостей, поэтому локальная компиляция здесь не была выполнена. Успешной сборку можно считать только после зелёного GitHub Actions run. Даже после компиляции нужно проверить генерацию, модели и бой в отдельном тестовом мире.
