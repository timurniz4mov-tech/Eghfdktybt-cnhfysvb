# Living Civilizations — строгая диагностическая сборка без worldgen

Эта сборка сделана для выяснения причины вылета при создании нового мира.

## Что именно отключено

- Убрана регистрация `ModFeatures.FEATURES` из главного класса мода.
- Удалены Java feature-классы поселения, замка и лагеря разбойников.
- Удалены все JSON `configured_feature` и `placed_feature`.
- Удалён biome modifier естественного спавна разбойников.
- Отключена регистрация правил естественного спавна бандита. Яйцо призыва бандита оставлено.

Сохранены NPC-типы и их рендереры, яйца призыва, предметы, монеты, экономика, команды и сохранение королевств.

## Установка (важно)

Это ПОЛНЫЙ проект, а не патч поверх предыдущей папки. Старые файлы worldgen нельзя оставлять в репозитории.

1. Сделай резервную копию текущего проекта.
2. Распакуй архив в новую пустую папку.
3. Загрузи ВСЁ содержимое этой папки в отдельную ветку или временный репозиторий GitHub. Не копируй поверх старых файлов без удаления старых.
4. Запусти GitHub Actions и дождись успешной сборки.
5. Удали все прежние `living-civilizations*.jar` из папки `.minecraft/mods`, оставь только один новый JAR.
6. Создай НОВЫЙ тестовый мир. Старый мир не используй для этой проверки.

## Как трактовать результат

- Если мир создастся, проблема с высокой вероятностью связана с worldgen JSON/feature/биомным спавном, которые теперь полностью отключены. Следующим шагом можно возвращать функции по одной.
- Если мир снова вылетит, причина не в пользовательских генераторах этого мода. Нужны `latest.log` и самый свежий файл из `crash-reports`.

В `latest.log` должна появиться строка: `Living Civilizations diagnostic build: custom world generation is disabled.`

## Ограничения

Это диагностическая версия: деревни, замки, лагеря и естественный спавн разбойников временно отсутствуют. Это не финальная игровая версия.
